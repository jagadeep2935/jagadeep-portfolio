## 🚀 Getting Started Locally

### 1. Prerequisites
- Node.js (v18 or higher recommended; v24 installed)
- npm or pnpm

### 2. Installation
```bash
# Navigate to the project directory
cd jagadeep-portfolio

# Install dependencies
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
Production assets are generated in the `dist/` directory.

### 5. Preview Production Build
```bash
npm run preview
```

## 🌐 Free Deployment to Vercel (For College DRIVE Registration)

You can deploy this portfolio to Vercel for free in under 2 minutes to get your public URL (e.g., `https://jagadeep-portfolio.vercel.app`).

### Option A: Deploy via GitHub (Recommended)

1. **Create a GitHub repository**:
   - Go to [GitHub](https://github.com) and create a new repository (e.g., `jagadeep-portfolio`).

2. **Push your code to GitHub**:
   ```bash
   git remote add origin https://github.com/jagadeep2935/jagadeep-portfolio.git
   git branch -M main
   git push -u origin main
   ```

3. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
   - Click **Add New...** -> **Project**.
   - Select your `jagadeep-portfolio` repository and click **Import**.
   - Vercel automatically detects **Vite** and sets:
     - Build Command: `npm run build`
     - Output Directory: `dist`
   - Click **Deploy**.

4. **Copy Public URL**:
   - In ~30 seconds, Vercel will give you a live production URL:
     `https://jagadeep-portfolio.vercel.app` (or custom name).
   - Paste this URL into your college DRIVE registration form!

### Option B: Deploy via Vercel CLI (Directly from Terminal)

```bash
# Install Vercel CLI globally
npm install -g vercel

# Run deploy from the project folder
vercel

# Follow terminal prompts, and for production:
vercel --prod
```
